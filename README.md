# Superstore Sales Dashboard (Excel Project)

## Overview

This project is a simple sales dashboard built in Excel using Superstore data. The goal was to understand sales performance, profit trends, and product/category insights in a clear and visual way.

I focused more on making the data easy to understand instead of doing complex analysis.

## What this project is about

* Tracking sales and profit performance
* Understanding which categories and sub-categories perform well
* Identifying top and low-performing products
* Building a simple interactive Excel dashboard

## Tools used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Basic data cleaning in Excel

## Dashboard features

* Sales and profit summary
* Category-wise breakdown
* Sub-category performance
* Regional performance view
* Trend analysis over time

## Key insights

* A few sub-categories generate most of the profit
* Some categories have high sales but low profit
* Certain regions consistently perform better
* Discounts have a clear impact on profit

## What I learned

This project helped me understand how Excel can be used for real business reporting. I also learned how to present data in a way that is easy to read and useful for decision-making.
